بخش دوم — دستور زبان ژاڤرک

1. ترتیب جمله

ساختار اصلی:

فاعل + مفعول + فعل

مثال:

Në Vü Drøklæv.

«من تو را دوست دارم.»

---

2. ضمایر

فارسی| ژاڤرک
من| "Në"
تو| "Vü"
او| "Ën"
ما| "Nëm"
شما| "Vën"
آنها| "Ënra"

---

3. فعل «بودن»

"Bë" = بودن

فارسی| ژاڤرک
هستم| "Bë"
هستی| "Bë"
هست| "Bë"
هستیم| "Bën"
هستید| "Bën"
هستند| "Bën"

مثال:

Në Bë Mëla.

«من خوب هستم.»

---

4. زمان گذشته

برای ساخت گذشته، فعل با پسوند مخصوص شخص تغییر می‌کند.

"Varn" = رفتن

فارسی| ژاڤرک
رفتم| "Varnë"
رفتی| "Varnï"
رفت| "Varnø"
رفتیم| "Varnëm"
رفتید| "Varnët"
رفتند| "Varnën"

---

5. زمان حال

فارسی| ژاڤرک
می‌روم| "Varna"
می‌روی| "Varni"
می‌رود| "Varnor"
می‌رویم| "Varnem"
می‌روند| "Varnen"

مثال:

Në Varna.

«من می‌روم.»

---

6. زمان آینده

برای ساخت آینده از پسوند "-ul" استفاده می‌شود.

Varnul

«خواهم رفت»

مثال:

Në Varnul.

«من خواهم رفت.»

---

7. منفی کردن

برای منفی کردن جمله از "Næ" استفاده می‌شود.

Næ Varna.

«نمی‌روم.»

Næ Bë Mëla.

«خوب نیستم.»

---

8. جمع بستن

برای جمع بستن اسم‌ها معمولاً از پسوند "-en" استفاده می‌شود.

Drøk  →  Drøken
دوست → دوستان

---

9. صفت

صفت معمولاً بعد از اسم قرار می‌گیرد.

Käv Mëla.

«خانه خوب»

Şevar Grön.

«شهر بزرگ»

---

10. سؤال

برای ساخت سؤال بله/خیر، ساختار جمله حفظ می‌شود و علامت "?" در پایان قرار می‌گیرد.

Vü Bë Mëla?

«آیا تو خوبی؟»

Ära = آره
Næ = نه

---

11. مالکیت

برای نشان دادن مالکیت از "de" استفاده می‌شود.

Käv de Në.

«خانه من»

VæƵ de Vü.

«بازی تو»

---

ساختارهای اصلی

جمله فعلی

فاعل + مفعول + فعل

Në Vü Drøklæv.

«من تو را دوست دارم.»

جمله وصفی

فاعل + Bë + صفت

Në Bë Mëla.

«من خوب هستم.»

---

قوانین پایه ژاڤرک

- ترتیب پایه جمله: فاعل + مفعول + فعل
- صفت معمولاً بعد از اسم قرار می‌گیرد.
- برای جمع از "-en" استفاده می‌شود.
- برای منفی کردن از "Næ" استفاده می‌شود.
- برای آینده از "-ul" استفاده می‌شود.
- افعال در زمان‌های مختلف تغییر می‌کنند.
- حروف ویژه مانند "Æ"، "Ø"، "Ë"، "Ƶ"، "Š"، "Ž" و "Ð" تلفظ اختصاصی دارند.
- کلمات ژاڤرک تا حد امکان مطابق شکل نوشتاری خود تلفظ می‌شوند.
