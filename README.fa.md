# ژاورک — Žavërk

یه زبان ساختگی با الفبا و دستور زبان خودش؛ چون ظاهراً زبان‌های دنیا هنوز کم بودن!
ژاورک یک زبان ساخته‌شده و آزمایشی است که الفبا، قواعد تلفظ و دستور زبان مخصوص خودش را دارد.

## دستور زبان

### ۱. ترتیب جمله

ساختار پایه:

**فاعل + مفعول + فعل**

نمونه:

```text
Në Vü Drøklæv.
```

«من تو را دوست دارم.»

### ۲. ضمایر

| فارسی | ژاورک |
|---|---|
| من | Në |
| تو | Vü |
| او | Ën |
| ما | Nëm |
| شما | Vën |
| آن‌ها | Ënra |

### ۳. فعل «بودن»

`Bë` به معنی «بودن» است.

| فارسی | ژاورک |
|---|---|
| هستم | Bë |
| هستی | Bë |
| هست | Bë |
| هستیم | Bën |
| هستید | Bën |
| هستند | Bën |

نمونه:

```text
Në Bë Mëla.
```

«من خوب هستم.»

### ۴. زمان گذشته

برای ساخت گذشته، فعل با پسوند متناسب با شخص تغییر می‌کند.

فعل نمونه: `Varn` — رفتن

| فارسی | ژاورک |
|---|---|
| رفتم | Varnë |
| رفتی | Varnï |
| رفت | Varnø |
| رفتیم | Varnëm |
| رفتید | Varnët |
| رفتند | Varnën |

### ۵. زمان حال

| فارسی | ژاورک |
|---|---|
| می‌روم | Varna |
| می‌روی | Varni |
| می‌رود | Varnor |
| می‌رویم | Varnem |
| می‌روند | Varnen |

نمونه: `Në Varna.` — «من می‌روم.»

### ۶. زمان آینده

برای ساخت آینده از پسوند `-ul` استفاده می‌شود.

`Varnul` یعنی «خواهم رفت».

نمونه:

```text
Në Varnul.
```

«من خواهم رفت.»

### ۷. منفی کردن

برای منفی کردن جمله از `Næ` استفاده می‌شود.

```text
Næ Varna.
Næ Bë Mëla.
```

«نمی‌روم.» و «خوب نیستم.»

### ۸. جمع بستن

برای جمع بستن اسم‌ها معمولاً از پسوند `-en` استفاده می‌شود.

`Drøk → Drøken`

«دوست → دوستان»

### ۹. صفت

صفت معمولاً بعد از اسم قرار می‌گیرد.

- `Käv Mëla.` — خانهٔ خوب
- `Şevar Grön.` — شهر بزرگ

### ۱۰. سؤال

برای پرسش‌های بله/خیر، ساختار جمله حفظ می‌شود و علامت سؤال در پایان می‌آید.

```text
Vü Bë Mëla?
```

«آیا تو خوبی؟»

- `Ära` — آره
- `Næ` — نه

### ۱۱. مالکیت

برای نشان دادن مالکیت از `de` استفاده می‌شود.

- `Käv de Në.` — خانهٔ من
- `VæƵ de Vü.` — بازی تو

## ساختارهای پایه

**جملهٔ فعلی:**

فاعل + مفعول + فعل

`Në Vü Drøklæv.` — من تو را دوست دارم.

**جملهٔ وصفی:**

فاعل + `Bë` + صفت

`Në Bë Mëla.` — من خوب هستم.

## خلاصهٔ قواعد

- ترتیب پایهٔ جمله: فاعل + مفعول + فعل
- صفت معمولاً بعد از اسم می‌آید.
- پسوند جمع معمولاً `-en` است.
- برای منفی کردن از `Næ` استفاده می‌شود.
- پسوند آینده `-ul` است.
- فعل‌ها در زمان‌های مختلف تغییر می‌کنند.
- حروف ویژه مانند `Æ`، `Ø`، `Ë`، `Ƶ`، `Š`، `Ž` و `Ð` تلفظ جداگانه دارند.
- واژه‌ها تا حد امکان مطابق شکل نوشتاری‌شان خوانده می‌شوند.

> این زبان و قواعد آن آزمایشی هستند و ممکن است در نسخه‌های بعدی تغییر کنند.
