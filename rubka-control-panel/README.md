# Rubka Control Panel

پنل وب برای کنترل بات Rubka و نمایش چت‌هایی که بات از آن‌ها پیام دریافت کرده است.

## اجرا در Pydroid 3

```text
pip install -r requirements.txt
```

قبل از اجرا، توکن بات را در متغیر محیطی `RUBKA_TOKEN` قرار بده یا مقدار placeholder داخل `app.py` را با توکن خودت عوض کن.

```text
python app.py
```

سپس پنل روی پورت `8080` اجرا می‌شود.

## امکانات

- نمایش وضعیت بات
- شمارش پیام‌های ورودی و خروجی
- نمایش چت‌های دیده‌شده
- جست‌وجوی چت‌ها
- نمایش پیام‌های زنده
- ارسال پیام با delay و count کنترل‌شده
- توقف ارسال‌های فعال
- فرمان‌های کنسولی `/send`, `/stop`, `/status`, `/help`

لیست چت‌ها بر اساس چت‌هایی ساخته می‌شود که بات واقعاً از آن‌ها پیام دریافت کرده است؛ پنل ادعا نمی‌کند که می‌تواند همه چت‌های حساب را بدون مشاهده آن‌ها فهرست کند.
